# prototype/kaggle

`benchmarks.csv` is the table of measured runs (one row per run; `python prototype/tools/build_benchmarks.py` renders it into [../../docs/models/README.md](../../docs/models/README.md)). Everything else the Kaggle scripts produce (generated notebooks `upload_*`, downloaded outputs `results_*`) is git-ignored: the findings live in [../../docs/](../../README.md) and the pictures worth keeping in `docs/img/`. The raw outputs of all earlier runs are in the reference repository `github.com/MarkAndreDuesing/layer-prototype` and in git history.
